# Data Versioning with DVC

## Project Objective
Demonstrate how DVC can be used to version datasets and track changes in a machine-learning workflow.

## MLOps Concepts
- Dataset versioning
- Reproducible data workflows
- DVC metadata
- Remote artifact storage concepts
- Experiment/workflow traceability

## Technology
**DVC | Git | Python | AWS S3 | MLOps**

## Portfolio Value
The repository demonstrates a foundational MLOps workflow where data is treated as a versioned project artifact rather than an unmanaged file.
